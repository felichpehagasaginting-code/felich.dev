### Overview
Blade Ascension is a browser-based 2D Action RPG built without external game engines. It demonstrates fundamental game development principles, sprite animation state machines, and mathematical collision physics.

### Technical Implementation
- **Custom Game Engine**: Written in **pure JavaScript (ES6)** using an explicit `requestAnimationFrame` game loop with delta-time calculation to ensure consistent game speed regardless of monitor refresh rates.
- **Physics & Combat**: Implements bounding-box (AABB) collision detection, directional attack hitboxes, combo counter state machines, and dynamic particle emission for spell effects.
