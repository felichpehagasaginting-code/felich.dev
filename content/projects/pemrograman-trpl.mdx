### Problem & Motivation
New software engineering students often struggle during programming matriculation due to setup friction in local IDE environments and a lack of immediate visual feedback during coding exercises.

### Technical Architecture & Implementation
- **Frontend Core**: Built with **Next.js (App Router)**, **TypeScript**, and **Tailwind CSS**, offering an intuitive IDE-like interface with syntax highlighting and instant error diagnosis.
- **Execution Sandbox**: Runs Python code snippets in real-time within a secure execution sandbox, presenting terminal outputs directly on screen.
- **Gamification & Progress**: Incorporates a gamification engine awarding Experience Points (XP), leveling badges, streak trackers, and dynamic student leaderboards to maximize engagement during foundational programming courses.
